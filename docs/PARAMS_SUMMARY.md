# F-16 parameters used by the sim

All values below are what the sim uses. SI conversion happens once, in
`AircraftParams.to_si()`. Page numbers are PDF pages of
`NASA Technical Paper 1538.pdf` (TP-1538), not the printed page numbers.
"README" is `README.txt` in the project root. "MATLAB" is
`reference/matlab/F16-Model-Matlab-main/`.

## Control surfaces (Table I p.49, Appendix A p.40–41)

| Surface | Limit | Actuator | Rate limit |
|---|---|---|---|
| Stabilator, symmetric δh | ±25° | 1st-order lag 0.0495 s (20.2/(s+20.2)) | 60 °/s |
| Stabilator, differential δd | ±5.375° per surface | same lag (per surface) | 60 °/s |
| Aileron (flaperon) δa | ±21.5° | 0.0495 s lag | 80 °/s |
| Rudder δr | ±30° | 0.0495 s lag | 120 °/s |
| Leading-edge flap δlef | 0…25° | 0.136 s lag | 25 °/s |
| Speed brake δsb | 0…60° | **placeholder** 30 °/s | — |

Sign conventions are TP-1538's: +δh = nose down, +δa = left roll, +δr = left
yaw, +δlef = leading edge down. Roll control uses δd = 0.25 δa (App. A p.41).

LEF schedule (App. A p.40):
δlef = 1.38·(2s+7.25)/(s+7.25)·α − 9.05·q̄/ps + 1.45 (deg), limited to 0…25°.

## Aerodynamics (Appendix B p.43–46, Table III p.51–97)

Coefficient build-up exactly as printed in Appendix B (Cx,t, Cz,t, Cm,t,
Cy,t, Cn,t, Cl,t), including:
- LEF increments scaled by (1 − δlef/25)
- aileron increments × δa/20 and rudder increments × δr/30
- speed-brake increments × δsb/60 (ΔCx,sb, ΔCz,sb, ΔCm,sb)
- stabilator effectiveness η(δh), ΔCm(α), ΔCnβ(α)·β, ΔClβ(α)·β
- deep-stall pitching moment ΔCm,ds(α, δh)
- CG transfer terms Cz,t(xcg,ref − xcg) and −Cy,t(xcg,ref − xcg)·c̄/b

Table ranges: α −20…90° (LEF tables −20…45°), β −30…30°, δh −25…25°.
Inputs outside the grid are clamped to the edge (TP-1538 states the data
covers exactly this range, p.15). The data are low-speed (M 0.1–0.2) and have
no compressibility, so TP-1538 says the model is valid only below about M 0.6 (p.38).

All 47 aero tables plus 3 thrust tables are in `data/*.csv`, generated by
`tools/export_aero.py`. Each file names its source.

## Propulsion (Appendix B p.46, Fig. 66 p.224–227, Table VI p.99)

- Idle / military / max thrust vs Mach (0.2…1.0) × altitude (0…15 240 m) from Table VI (SI).
- Throttle gearing (Fig. 66b): power P1 = 50·thr/0.77 up to the military
  detent (≈77 % travel), then linear to 100 at full travel. The detent position is digitized.
- Power dynamics (Fig. 66a): commanded P2 and first-order lag P3 with
  1/τ = 5 s⁻¹ inside the AB region, otherwise 1/τ(P2−P3) from Fig. 66c
  (1.0 s⁻¹ up to ΔP = 25, falling linearly to 0.1 s⁻¹ at ΔP = 50).
- Thrust: P3 < 50: T = Tidle + (Tmil − Tidle)·P3/50; else T = Tmil + (Tmax − Tmil)·(P3 − 50)/50.
- Thrust acts along body +X through the CG (no offset is given).

## Flight control system (Appendix A, Figs. 62–65 p.216–224)

The pitch, roll and yaw "control system A" block diagrams are implemented
gain for gain. The breakpoints of the schedule figures were digitized from
the plots (see GAPS for each). Main numbers:
- Pitch: normal-acceleration command, +8 g command limit, negative-g limit
  scheduled with q̄ (Fig. 62b), α limiter 0.322 g/deg above 15° and
  1.322 g/deg above 20.4°, which gives an α limit of about 25° in 1 g (p.40),
  α feedback 0.5, PI loop (integrator 5/s, ±25° clamp), q̄-scheduled gains.
- Roll: roll-rate command up to 308 °/s (p.40), gain 0.12 °/(°/s), α ≥ 29°
  spin prevention through yaw-rate feedback 8.34.
- Yaw: stability-axis yaw damper, ARI 0.075/deg, ay feedback 19.32, pilot
  rudder faded out between α 20 and 30°, spin prevention 0.75 °/(°/s) at α ≥ 29°.

## Landing gear (README.txt)

Positions are relative to the README reference point (the front of the
nozzle), in inches, Z up. The CG is at X = 201.3.

| Point | X | Y | Z | Body (m, fwd/right/down from CG) |
|---|---|---|---|---|
| Nose gear contact | 332.2 | 0 | −73 | (+3.325, 0, +1.854) |
| Main gear contact | 171.9 | ±46.7 | −73 | (−0.747, ±1.186, +1.854) |
| Pilot eye | 384.7 | 0 | 33.2 | (+4.658, 0, −0.843) |
| Radome tip | 525.0 | 0 | −13 | (+8.222, 0, +0.330) |
| Top of vertical tail | 0 | 0 | 127.5 | (−5.113, 0, −3.239) |
| Wingtip | 128 | ±197 | 0 | (−1.862, ±5.004, 0) |

- Z = −73 in is the ground line: fin top 127.5 in minus the overall height
  16 ft 8.5 in (200.5 in) gives −73. So these points are the static tyre contact points.
- Stroke: MLG 10.5 in (0.267 m), NLG 10.0 in (0.254 m).
- Static rolling radius: MLG 11.0 in (0.279 m), NLG 7.5 in (0.191 m).
- Static load split from geometry: nose 18.3 %, each main 40.8 %.

## Flaps (README.txt)

The README lists trailing-edge flap (TEF) settings: 20° for take-off,
approach and landing, −2° high speed. There is no TEF aerodynamic data in
any source, so the TEF is visual only (see GAPS).

## Atmosphere

International Standard Atmosphere (troposphere lapse 6.5 K/km to 11 km,
isothermal above). g = 9.80665 m/s². This is a standard model, not aircraft data.
